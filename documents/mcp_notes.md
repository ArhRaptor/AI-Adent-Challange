# Model Context Protocol и инструменты

## MCP
MCP позволяет приложению получать описание доступных инструментов и вызывать их через согласованный интерфейс. Сервер публикует tools, клиент запрашивает список и вызывает нужный tool.

## Orchestration
Orchestrator координирует несколько инструментов или серверов, передаёт результат одного вызова следующему и контролирует порядок действий.

## Пример цепочки
search_products → analyze_products → save_report. Поиск возвращает данные, аналитика их обрабатывает, а сервис отчётов сохраняет результат.

## Ограничения
Успешный вызов инструмента не равен корректному выводу LLM. Результаты инструментов нужно проверять и не подменять догадками.
