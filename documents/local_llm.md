# Локальные LLM и Ollama

## Runtime
Ollama запускает модели на локальном компьютере и предоставляет API на http://localhost:11434.

## Генерация
Endpoint `/api/chat` принимает model и messages и возвращает сообщение assistant. Для одиночной генерации существует `/api/generate`.

## Embeddings
Endpoint `/api/embed` принимает model и input и возвращает embeddings. Для Day 28 используется `nomic-embed-text`.

## Полностью локальный RAG
Для полностью локальной работы должны быть локальны документы, построение embeddings, хранение индекса, embedding вопроса, поиск и генерация ответа. Если query embedding создаётся через облачный API, такой pipeline не полностью локален.

## Ограничения компактной модели
Небольшая модель может быстро отвечать, но ошибаться в вычислениях, фактах и использовании истории. Корректная инфраструктура не гарантирует корректного содержания ответа.
