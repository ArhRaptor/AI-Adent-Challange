# Учебная база знаний для Day 28

## Назначение
Этот корпус используется для локального RAG: загрузка документов, разбиение на чанки, создание embeddings, поиск релевантных фрагментов и генерация ответа с источниками.

## Конвейер
Ingestion → Chunking → Embedding → Index → Retrieval → Context → Generation.

## Локальный режим
Ollama обслуживает локальные модели. `nomic-embed-text` создаёт embeddings документов и запросов через `/api/embed`, а `qwen2.5-coder:0.5b` генерирует ответы через `/api/chat`. Векторный поиск по JSON-индексу выполняется локально в Python.

## Ограничение
Чанки, полученные одной embedding-моделью, нельзя корректно сравнивать с query embeddings другой модели. Поэтому индекс Gemini нужно перестроить для Ollama.
