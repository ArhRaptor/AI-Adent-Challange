Агент: память и управление задачей

Short-term memory содержит недавние сообщения и быстро ограничивается по длине.
Working memory хранит детали текущей работы: выбранный шаг, промежуточные решения и временные параметры.
Long-term memory хранит устойчивые сведения, которые могут пригодиться в будущих задачах.

Conversation history — последовательность реплик. Task state — компактная структура с целью, уточнениями, ограничениями и терминами пользователя. Это не одно и то же.

Task State Machine может включать planning, execution, validation и done. Переходы между этапами требуют выполнения определённых условий. Invariants запрещают нарушения архитектурных правил.

История диалога помогает понять местоимения и продолжения, но не должна подменять факты из документальной базы знаний.
