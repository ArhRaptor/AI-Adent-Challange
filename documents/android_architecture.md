# Android: MVVM и Jetpack Compose

## MVVM
Model отвечает за данные и бизнес-логику. View отображает состояние и пользовательский интерфейс. ViewModel подготавливает UI state, обрабатывает действия пользователя и связывает UI с логикой приложения.

## ViewModel
ViewModel предоставляет состояние экрана, например через StateFlow, и реагирует на события UI. Это позволяет отделить отображение от загрузки данных и бизнес-правил.

## Jetpack Compose
Compose описывает UI декларативно. Когда наблюдаемое состояние меняется, Compose может выполнить recomposition нужных частей интерфейса.

## Repository
Repository скрывает детали источников данных: локальную базу, сеть и кэш. ViewModel обращается к repository, не встраивая HTTP-логику непосредственно в composable-функции.

## Пример
Экран товаров показывает список, поиск и фильтрацию. ViewModel хранит запрос поиска и состояние списка, repository получает товары, а composable-функции отображают UI.
