# Embeddings и поиск

## Embedding
Embedding — числовой вектор, представляющий содержание текста. Для поиска вопрос и документы кодируются одной совместимой embedding-моделью.

## Cosine similarity
Косинусная близость оценивает направление векторов: dot(a,b) / (norm(a) * norm(b)). Чем выше score, тем ближе векторы в данном пространстве. Сам по себе высокий score не гарантирует фактическую релевантность.

## Top-K
Top-K выбирает K лучших результатов даже тогда, когда все результаты плохо подходят. Поэтому полезны фильтрация по порогу similarity, reranking и проверки достаточности контекста.

## Query rewrite
Переформулирование вопроса может убрать разговорные слова и восстановить предмет из истории диалога. Исходный вопрос при этом остаётся основой итогового ответа.

## Локальный индекс
В учебном проекте JSON содержит text, metadata и embedding. Поиск выполняется перебором всех векторов; для небольшого корпуса этого достаточно.
