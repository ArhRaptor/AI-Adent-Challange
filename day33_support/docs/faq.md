# HelpDesk Cloud — FAQ (демонстрационный продукт)

## Почему не получается войти?
После пяти последовательных неудачных попыток входа система может временно заблокировать авторизацию. Проверьте правильность пароля и дождитесь окончания блокировки. Если блокировка не снимается, передайте номер тикета сотруднику поддержки. Не сообщайте пароль или коды MFA.

## Как восстановить пароль?
На странице входа выберите «Забыли пароль?». Ссылка для сброса отправляется на адрес аккаунта. Проверьте папку «Спам». Если письма нет, создайте тикет поддержки.

## Что делать с MFA?
Если включена многофакторная аутентификация, при входе понадобится второй фактор. При потере доступа к MFA обратитесь к администратору организации. Сотрудники поддержки не должны запрашивать одноразовые коды.

## Где посмотреть статус тикета?
Укажите номер обращения вида T-1001. Ассистент может получить статус через MCP-инструмент get_ticket.
