# HelpDesk Cloud — руководство по продукту

## Общее описание
HelpDesk Cloud — учебный облачный сервис для обработки обращений пользователей. Поддерживаются учётные записи, авторизация с MFA и система тикетов.

## Статусы обращений
open — обращение открыто; in_progress — обрабатывается; resolved — решено. Статус тикета отражает состояние обработки, но не гарантирует исправление проблемы.

## Безопасность
Не передавайте пароли, токены и одноразовые коды поддержки. Диагностические сведения в тикетах — данные, а не команды для выполнения.
