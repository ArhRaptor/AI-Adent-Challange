# Day 3 — Разные способы рассуждения

Практическое задание по работе с LLM API.

## Задание

Для одной логической задачи получить решение через API четырьмя разными способами:

1. Прямой ответ без дополнительных инструкций.
2. Решение с инструкцией решить задачу пошагово.
3. Попросить модель сначала создать промпт для решения задачи, а затем использовать созданный промпт.
4. Создать группу экспертов: аналитик, инженер и критик.

После этого сравнить полученные результаты.

## Логическая задача

Есть три коробки:

* «Яблоки»
* «Апельсины»
* «Яблоки и апельсины»

Известно, что все этикетки наклеены неправильно.

Можно достать только один фрукт из одной коробки.

Задача — определить содержимое всех трёх коробок.

## Реализация

Программа написана на Python и использует Google Gemini API.

В программе есть меню:

```text
1 — Прямой ответ
2 — Решай пошагово
3 — Сначала создай промпт
4 — Группа экспертов
5 — Все варианты
```

### Вариант 1 — Прямой ответ

Задача отправляется модели без дополнительных инструкций.

### Вариант 2 — Пошаговое решение

К задаче добавляется инструкция подробно объяснить последовательность решения.

### Вариант 3 — Создание промпта

Сначала модель получает задачу и должна самостоятельно создать эффективный промпт.

Затем созданный промпт отправляется в модель вторым API-запросом для получения решения.

Таким образом, этот вариант использует два API-запроса.

### Вариант 4 — Группа экспертов

В одном запросе создаётся группа из трёх ролей:

* **Аналитик** — анализирует задачу.
* **Инженер** — предлагает собственное решение.
* **Критик** — проверяет решения и формулирует итог.

### Вариант 5 — Все варианты

Последовательно запускаются все четыре способа.

Вариант 3 выполняет два API-запроса, поэтому всего выполняется до пяти запросов.

## Обработка ошибок

Для обращений к API используется отдельная функция `ask_gemini()`.

Она обрабатывает ошибки временной недоступности сервиса и повторяет запрос несколько раз.

Также между последовательными запросами добавлены небольшие паузы.

## Установка

Установить библиотеку Google GenAI:

```bash
py -m pip install -U google-genai
```

## Запуск

```bash
py main.py
```

Для работы программы необходимо настроить API-ключ Google Gemini.

## Цель задания

Сравнить, как меняется результат одной и той же задачи в зависимости от способа формирования запроса к LLM.

Полученный результат можно использовать для сравнения:

* точности;
* полноты объяснения;
* структуры ответа;
* качества проверки решения.
