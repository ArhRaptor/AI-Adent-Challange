# День 6 — Первый агент

## Задание

Реализовать простого AI-агента, который:

- принимает запрос пользователя;
- отправляет запрос в LLM через API;
- получает ответ от модели;
- выводит результат пользователю через интерфейс.

Дополнительное требование:

- агент должен быть отдельной сущностью;
- логика взаимодействия с LLM должна быть инкапсулирована внутри агента.

---

## Цель

Цель задания — перейти от простого вызова LLM API к созданию отдельного программного компонента, который отвечает за взаимодействие с языковой моделью.

В предыдущих заданиях API можно было вызывать непосредственно из основной части программы.

В этом задании работа с LLM вынесена в отдельный класс:

`GeminiAgent`

Основная программа взаимодействует уже не напрямую с Gemini API, а с агентом.

---

## Используемые технологии

- Python
- Google Gemini API
- библиотека `google-genai`
- CLI (Command Line Interface)

В качестве LLM используется модель:

`gemini-3.6-flash`

---

## Архитектура

Работу программы можно представить следующим образом:

```text
Пользователь
    ↓
CLI
    ↓
GeminiAgent
    ↓
Gemini API
    ↓
GeminiAgent
    ↓
CLI
    ↓
Пользователь
```

CLI отвечает за взаимодействие с пользователем.

`GeminiAgent` отвечает за взаимодействие с языковой моделью.

---

## Реализация агента

Агент реализован в виде отдельного класса:

```python
class GeminiAgent:
    def __init__(self, model="gemini-3.6-flash"):
        self.client = genai.Client()
        self.model = model

    def ask(self, user_message):
        response = self.client.models.generate_content(
            model=self.model,
            contents=user_message
        )

        return response.text
```

Класс хранит:

- клиент Gemini API;
- название используемой модели;
- логику отправки запроса;
- логику получения ответа.

---

## Инкапсуляция логики

Одно из основных требований задания — логика запроса и ответа должна быть инкапсулирована внутри агента.

В данной реализации это требование выполнено.

Основная программа не вызывает Gemini API напрямую.

Вместо этого она передаёт сообщение пользователя агенту:

```python
answer = agent.ask(user_message)
```

После этого `GeminiAgent` самостоятельно:

1. принимает сообщение;
2. отправляет его в Gemini API;
3. получает ответ модели;
4. извлекает текст ответа;
5. возвращает результат основной программе.

Таким образом, детали взаимодействия с LLM скрыты внутри класса `GeminiAgent`.

---

## CLI-интерфейс

Для взаимодействия с агентом используется простой консольный чат.

Пользователь может вводить сообщения:

```text
Вы: Что такое нейросеть?
```

Агент отправляет запрос в Gemini и выводит полученный ответ:

```text
Агент:
Нейросеть — это...
```

После получения ответа программа продолжает работать, поэтому пользователь может отправить следующий запрос.

Для завершения работы используется команда:

```text
exit
```

---

## Обработка ошибок

Вызов агента выполняется внутри конструкции:

```python
try:
    answer = agent.ask(user_message)
except Exception as error:
    print("Ошибка при обращении к API:")
    print(error)
```

Если при обращении к Gemini API возникнет ошибка, программа не завершится аварийно, а покажет информацию об ошибке пользователю.

---

## Полный код

```python
from google import genai


class GeminiAgent:
    def __init__(self, model="gemini-3.6-flash"):
        self.client = genai.Client()
        self.model = model

    def ask(self, user_message):
        response = self.client.models.generate_content(
            model=self.model,
            contents=user_message
        )

        return response.text


def main():
    agent = GeminiAgent()

    print("=" * 60)
    print("ДЕНЬ 6 — ПЕРВЫЙ АГЕНТ")
    print("=" * 60)

    print()
    print("Простой CLI-агент на базе Gemini.")
    print("Введите сообщение.")
    print("Для выхода напишите: exit")

    while True:
        print()

        user_message = input("Вы: ")

        if user_message.lower() == "exit":
            print("Агент: До свидания!")
            break

        try:
            answer = agent.ask(user_message)

            print()
            print("Агент:")
            print(answer)

        except Exception as error:
            print()
            print("Ошибка при обращении к API:")
            print(error)


if __name__ == "__main__":
    main()
```

Для запуска программы:


После запуска появляется CLI-интерфейс:

## Результат

В рамках Day 6 был реализован первый простой AI-агент.

Агент:

- является отдельной сущностью `GeminiAgent`;
- принимает сообщения пользователя;
- самостоятельно вызывает LLM через Gemini API;
- получает ответ модели;
- возвращает результат в CLI-интерфейс;
- поддерживает несколько последовательных запросов;
- обрабатывает ошибки API.

Главное отличие от простого вызова API заключается в разделении ответственности.

CLI занимается взаимодействием с пользователем, а `GeminiAgent` инкапсулирует всю логику взаимодействия с LLM.

Таким образом, требования задания Day 6 выполнены.

---

## Вывод

В этом задании был сделан переход от прямого вызова LLM API к простой агентной архитектуре.

Основная идея:

```text
Интерфейс → Агент → LLM
```

Интерфейс не должен знать детали работы с Gemini API.

Эту ответственность берёт на себя отдельный объект `GeminiAgent`.

Такой подход позволяет в дальнейшем расширять агента: добавлять память диалога, системные инструкции, инструменты (tools), работу с внешними API и другие возможности.
