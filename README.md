# Day 4 — Temperature

Практическое задание по работе с LLM API.

## Задание

Выполнить один и тот же запрос к LLM с разными значениями параметра `temperature`:

* `temperature = 0`
* `temperature = 0.7`
* `temperature = 1.2`

После этого сравнить полученные ответы по:

* точности;
* креативности;
* разнообразию.

Также определить, для каких задач лучше подходит каждое значение `temperature`.

## Используемая задача

Для эксперимента использовался один и тот же запрос:

> Придумай короткую историю о роботе, который впервые оказался на Земле.

Требования:

* 100–150 слов;
* история должна иметь начало, развитие и конец;
* текст должен быть понятным.

Во всех трёх запросах условие задачи оставалось одинаковым. Менялся только параметр `temperature`.

## Реализация

Программа написана на Python и использует Google Gemini API.

Для задания используется параметр:

```python
config=types.GenerateContentConfig(
    temperature=temperature
)
```

Программа имеет меню:

```text
1 — Temperature = 0
2 — Temperature = 0.7
3 — Temperature = 1.2
4 — Все варианты
```

При выборе `4` программа последовательно отправляет один и тот же запрос с тремя значениями `temperature`.

Ответ получился последовательным и предсказуемым.

Ответ стал более выразительным, но при этом сохранил понятную структуру.

Ответ оказался наиболее творческим и содержал больше необычных деталей.

## Сравнение

| Temperature | Точность | Креативность | Разнообразие |
| ----------: | -------- | ------------ | ------------ |
|           0 | ⭐⭐⭐⭐⭐    | ⭐⭐⭐          | ⭐⭐           |
|         0.7 | ⭐⭐⭐⭐⭐    | ⭐⭐⭐⭐         | ⭐⭐⭐⭐         |
|         1.2 | ⭐⭐⭐⭐     | ⭐⭐⭐⭐⭐        | ⭐⭐⭐⭐⭐        |

По результатам эксперимента видно, что изменение `temperature` влияет прежде всего на вариативность и творческий характер ответа.

При `temperature = 0` ответ получается наиболее предсказуемым.

При `temperature = 0.7` получается хороший баланс между стабильностью и креативностью.

При `temperature = 1.2` ответ становится более разнообразным и творческим, однако предсказуемость результата снижается.

Интересно, что все три ответа сохранили общую понятную структуру, несмотря на разные значения параметра. При этом во всех трёх вариантах модель использовала похожий художественный приём — встречу робота с бабочкой.

## Выводы

### Temperature = 0

Лучше использовать для задач, где важны:

* стабильность;
* предсказуемость;
* одинаковый формат ответа;
* точное выполнение инструкции.

Например:

* классификация текста;
* извлечение информации;
* обработка структурированных данных;
* стандартные ответы.

### Temperature = 0.7

Подходит для задач, где нужен баланс между точностью и творчеством.

Например:

* написание текстов;
* объяснение материала;
* генерация идей;
* обычный диалог;
* создание нескольких вариантов текста.

### Temperature = 1.2

Подходит для творческих задач, где важны разнообразие и необычные идеи.

Например:

* написание историй;
* brainstorming;
* создание сюжетов;
* рекламные идеи;
* творческие концепции.

При этом высокая `temperature` не означает автоматически более качественный ответ. Увеличение значения делает результат более вариативным, но может снизить стабильность и предсказуемость.

## Общий вывод

В эксперименте одна и та же задача была отправлена модели с тремя разными значениями `temperature`.

Результаты показали, что:

* низкая температура делает ответы более стабильными и предсказуемыми;
* средняя температура даёт баланс между стабильностью и креативностью;
* высокая температура увеличивает разнообразие и творческий характер ответов.

Таким образом, значение `temperature` следует выбирать в зависимости от задачи:

**точность и стабильность → низкая temperature**

**баланс → средняя temperature**

**креативность и разнообразие → высокая temperature**
