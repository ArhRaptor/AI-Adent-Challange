# AI-Adent-Challange

Учебный проект по работе с LLM API на Python и Google Gemini.

## День 1 — Первый запрос к LLM

Задача:

* отправить запрос к LLM через API;
* получить ответ;
* вывести ответ в консоль.

Используется:

* Python
* Google Gemini API
* библиотека `google-genai`

## День 2 — Контроль ответа LLM

Задача — отправить один и тот же запрос с разным уровнем контроля ответа.

Реализованы 3 варианта:

### 1. Без ограничений

Запрос отправляется в модель без дополнительных ограничений.

```text
Пользовательский prompt → Gemini → ответ
```

### 2. Формат + ограничение длины

К запросу добавляется:

* явное описание формата ответа;
* ограничение длины ответа;
* технический лимит `max_output_tokens=1000`.

```text
Формат:
1. Краткое определение.
2. Один пример.
3. Краткий итог.
```

### 3. Stop Sequence

Используется `stop_sequences=["STOP"]`.

Модель получает инструкцию завершить ответ специальной последовательностью `STOP`.

Когда модель генерирует `STOP`, генерация прекращается.

## Меню программы

При запуске можно выбрать:

```text
1 — Без ограничений
2 — Формат + ограничение длины
3 — Stop sequence
4 — Все варианты
```

Вариант `4` позволяет сравнить результаты всех трёх подходов.

## Установка

Установить библиотеку Google GenAI:

```bash
py -m pip install -U google-genai
```

## API ключ

Для работы программы необходим API ключ Google Gemini.

Ключ не должен храниться непосредственно в коде или публиковаться на GitHub.

## Запуск

```bash
py main.py
```

После запуска программа попросит ввести запрос и выбрать вариант обработки.

## Используемая модель

```text
gemini-3.6-flash
```

## Результат

В результате реализовано сравнение одного и того же запроса с разным уровнем контроля ответа через API:

* без ограничений;
* с контролем формата и длины;
* с условием остановки через `stop sequence`.

Также записано видео с демонстрацией работы программы.
