\# AI-Adent-Challange



\## Задание. День 1 — первый запрос к LLM через API



Цель задания:



\* отправить запрос в LLM через API;

\* получить ответ;

\* вывести ответ в консоль (CLI).



\## Что делает программа



Программа написана на Python и использует \*\*Google Gemini API\*\*.



После запуска программа предлагает пользователю ввести вопрос. Введённый текст отправляется в Gemini через API, после чего полученный ответ выводится в консоль.



Для завершения программы необходимо ввести:



`exit`



\## Пример работы



```text

Вы: Что такое API?



Gemini: API — это интерфейс, который позволяет разным программам взаимодействовать друг с другом...

```



\## Используемые технологии



\* Python 3.13

\* Google Gemini API

\* библиотека `google-genai`

\* Git

\* GitHub

\* PowerShell (CLI)



\## Установка



Установить библиотеку Google GenAI:



```bash

py -m pip install -U google-genai

```



\## Настройка API-ключа



Для работы программы необходим API-ключ Google Gemini.



Ключ хранится в переменной окружения:



```text

GEMINI\_API\_KEY

```



API-ключ \*\*не хранится в исходном коде и не публикуется в GitHub\*\*.



\## Запуск



Запустить программу командой:



```bash

py main.py

```



После запуска введите свой вопрос:



```text

Вы: Объясни простыми словами, что такое Python?

```



Программа отправит запрос в Gemini и выведет полученный ответ.



Для завершения:



```text

Вы: exit

```
